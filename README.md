# Papollo-Healthcare-Analysis
Healthcare Data Analysis Dashboard using Excel and Power BI
Project Overview

This project presents an interactive healthcare analytics dashboard developed using Microsoft Excel and Power BI to analyze hospital performance and patient-related information
#Tools & Technologies

Microsoft Excel – Data preparation and analysis

Microsoft Power BI – Dashboard development and data visualization

#Key Performance Indicators

Total Billing Amount

Patient Admission Date

Patient Discharge Date

Patient Follow-up Date

Dashboard Visualizations

Bed Occupancy Analysis (Private, General, ICU)

Doctor Feedback Volume

Diagnosis Type Analysis

Health Insurance Amount vs. Billing Amount Trends

Admission Date Analysis

#Project Objective
To transform healthcare data into meaningful insights through interactive visualizations, helping understand hospital operations, patient diagnosis patterns, bed occupancy, and financial trends.
